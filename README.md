# 🏠 HomeSaathi

HomeSaathi is a full-stack property rental platform inspired by modern vacation rental applications. It enables users to explore, list, and manage rental properties through a clean and responsive interface.

Built using the MERN backend stack (Node.js, Express.js, MongoDB) with EJS templating, the project follows the MVC architecture and focuses on authentication, CRUD operations, location-based listings, and an improved user experience.

---

## Features

### Authentication & Authorization
- User Signup and Login
- Secure password hashing using Passport.js
- Session-based authentication
- Authorization for listings and reviews

### Property Listings
- Create, Edit and Delete Listings
- Upload listing images using Cloudinary
- Property details page
- Category selection for listings

### Search & Discovery
- Search listings by keywords
- Category-based filtering
- Sorting (Price Low–High, High–Low, Newest)
- Pagination for efficient browsing

### Maps & Location
- Geocoding using Mapbox
- Interactive map with property marker and popup

### User Features
- Wishlist
- User Profile
- Review and Rating System

### Performance Improvements
- MongoDB Indexes for faster queries
- Debounced Search
- Lazy Loading Images
- Skeleton Loader
